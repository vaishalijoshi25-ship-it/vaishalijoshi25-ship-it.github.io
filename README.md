# Vaishali Joshi - Portfolio

Plain HTML, CSS and JavaScript. No build step and nothing to install.

## Files
- index.html - page content
- style.css - all styling (colors and fonts are the variables at the top)
- script.js - copy-to-clipboard buttons in the Contact section

## Run locally
Open index.html in a browser.

## Deploy
- Vercel: import this folder (or a GitHub repo containing it) as a new project. Framework preset: Other.
- GitHub Pages: push the files to a repo, then Settings > Pages > deploy from the main branch.

## Adding live demo links
In index.html, each project has a link at the bottom (class "more"). Change its href to the project's live URL
and its text to "View live demo".
